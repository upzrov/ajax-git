# ajax-git

Використані команди:

- `git branch` - керування гілками. Без аргументів відображає список усіх локальних гілок із позначенням поточної; також використовується для їх створення (`git branch <назва>`), перейменування (`git branch -m`) або видалення (`git branch -d`).
- `git remote` - керування підключеннями до віддалених репозиторіїв. Показує список налаштованих серверів (наприклад, з прапорцем `-v`), дозволяє додавати нові адреси (`git remote add`) та перевіряти зв'язок.
- `git add` - перенесення змінених або нових файлів до області підготовки (staging area / index) для включення в наступний комміт (наприклад, `git add .` для підготовки всіх змін).
- `git commit` - фіксація підготовлених змін у локальній історії проєкту у вигляді нового комміту із супровідним повідомленням (`git commit -m "коментар"`).
- `git pull --rebase` - отримання актуальних змін із віддаленого репозиторію та автоматичне перенесення ваших локальних коммітів поверх них, що запобігає створенню зайвих коммітів злиття (merge commits) і зберігає лінійну історію.
- `git push` - вивантаження локальних коммітів на віддалений сервер (наприклад, `git push origin <гілка>`) для публікації змін та синхронізації з командою.
